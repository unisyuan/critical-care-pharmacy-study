# 重症藥學學習室

以提供的 ACCP/ASHP 2024 Critical Care Pharmacy 教材製作之繁體中文閱讀與測驗網頁。

- 20 章詳細重點整理（複習架構、分主題條目、比較表及原稿頁碼），可下載各章筆記。
- 20 章連續閱讀全文，保留原標號、層級及表格。
- 專有名詞、藥名與參考文獻保留英文。
- 339 題 Self-Assessment Questions / Patient Cases，支援隨機練習與錯題複習。
- 原 PDF 對照、各章 Markdown 下載。
- 閱讀與練習紀錄儲存在目前瀏覽器。

## 開啟網頁

直接開啟 `index.html`，或在 GitHub repository 的 Settings → Pages 選擇「Deploy from a branch」、`main`、`/(root)`。

所有路徑皆為相對路徑，可部署於 GitHub Pages repository 網址。無需安裝或建置。

## 內容來源

內容及教材答案依提供的 2024 年課程檔案翻譯。原稿的內部不一致之處另附核對註。教材及翻譯內容未授予開源再散布授權。
